# Pablo Martínez-Miravé — Personal Academic Website

Personal academic webpage of Pablo Martínez-Miravé, Postdoctoral Fellow at the Niels Bohr Institute, University of Copenhagen.

Website: https://pamarmi.github.io/

## About

This repository contains the source code and content for my academic webpage, including:

- Research interests
  - Neutrino astrophysics
  - Particle astrophysics
  - Stellar evolution phenomenology
  - Cosmology and particle physics
- Publications
- Talks and conference presentations
- Teaching and mentoring activities
- Outreach and dissemination
- Curriculum vitae
- Contact information

## Learning exercise

This repository also served as a lightweight learning exercise in web development and version-controlled project management. The goal was not only to build an academic webpage, but also to gain hands-on experience with:

- HTML and webpage structure
- Styling and layout design
- Git and GitHub workflows
- Repository organisation
- GitHub Pages deployment
- Iterative software development practices

## Technologies

Built using:

- HTML5
- CSS
- GitHub Pages

## Local development

Clone repository:

```bash
git clone https://github.com/pamarmi/pamarmi.github.io.git
cd pamarmi.github.io
```

Open locally:

```text
index.html
```

or run:

```bash
python -m http.server 8000
```

then open:

```text
http://localhost:8000
```
